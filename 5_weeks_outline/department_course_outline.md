# MSIS-2402 — Course Outline <br> 5 Weeks

[← Course home](../README.md) · [Course outline](README.md) · **Department outline**

The department's official module descriptions for MSIS-2402, Database
Management Systems: Fundamentals of SQL. Each week below matches a
`week*/` folder in this repo.

## Week 1: Database Concepts and SQL Fundamentals
This module introduces the foundations of relational
databases and SQL. Students learn how relational data
is organized and develop basic skills for creating,
retrieving, filtering, summarizing, and modifying data.
The module establishes the core database and SQL concepts
used throughout the remainder of the course.

## Week 2: Working with Multiple Tables and Complex Queries
This module develops students' ability to work with
related data across multiple tables and to solve
more complex information needs using SQL. Students
learn strategies for combining, structuring, and
decomposing queries and for reasoning carefully about
query results.

## Week 3: SQL for Data Analytics
This module explores how SQL can be used for
contemporary data analysis. Students apply SQL
to transform, summarize, compare, and analyze
data and are introduced to more advanced analytical
capabilities of modern relational database systems.

## Week 4: Introduction to Web Database Applications
This module introduces the role of databases in web
and other modern applications. Students develop a
broad understanding of application architecture and
the relationship among user interfaces, application
logic, and databases. Basic web technologies and a
simple database-backed application are used to
demonstrate how data moves through a real application.

## Week 5: Modern Data Systems and Database Management
This module broadens the course beyond SQL and
relational databases to introduce the modern data
landscape and practical database management
considerations. Students develop general awareness
of different types of data systems, database
technologies, data platforms, and the operational,
security, performance, and governance issues involved
in managing organizational data.
