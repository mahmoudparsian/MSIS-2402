## Orientation Notebooks

Open these first — they need nothing but the course software. Run them
from **inside this folder**:

```bash
cd 5_weeks_outline
marimo edit sql_notebook_01.py
```

| Notebook | What it covers |
|---|---|
| [`sql_notebook_01.py`](sql_notebook_01.py) | **Welcome to Marimo and DuckDB** — what a notebook is, your first table, your first SQL questions, and what you'll learn in the five weeks |
| [`sql_notebook_02.py`](sql_notebook_02.py) | **SQL 101** — creating tables, `SELECT`, `WHERE`, sorting, aggregates, `GROUP BY`, and `INSERT` / `UPDATE` / `DELETE`, with charts |
| [`plot_util.py`](plot_util.py) | Table and chart helpers that `sql_notebook_02.py` imports — not a notebook itself |
