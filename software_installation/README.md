## Choose Your Operating System

This folder has two completely separate, self-contained guides — one for
each operating system. Pick the one that matches your computer and follow
**only that folder** from here on; you won't need to open the other one.

| Operating system | Go to |
|---|---|
| 🍎 **Mac** | [`macbook/README.md`](macbook/README.md) |
| 🪟 **Windows** | [`windows/README.md`](windows/README.md) |

## What the Guides Cover

| Step | What you do | When |
|:---:|---|---|
| **0** | Get the course files | **Before the first class** |
| **1** | Install Python | **Before the first class** |
| **2** | Install and check DuckDB, Marimo, Pandas, Matplotlib, and sqlglot (one script) | **Before the first class** |
| **3** | Verify everything together in a Marimo notebook | **Before the first class** |
| **4** | Install Java, then the qStudio SQL editor | **Before the first class** |
| **5** | Install MySQL (used in Weeks 4–5) | **Before the first class** |
| **6** | Install the lock-down browser and take the practice quiz | At least **one week before the Final Exam** |

Each guide also has its own troubleshooting page for common Day-1
problems.

**Set aside about an hour and fifteen minutes** for Steps 0–5, and do them
**before the first class**.
